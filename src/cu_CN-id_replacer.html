使用说明

匹配规则：工具会查找文本中所有形如 {{类别|中文名}} 的片段。

  • 当 类别 为 物品 时，从语言文件的 main 字典中查找；
  • 当 类别 为 地层 时，从 layer 字典中查找；
  • 其他类别（如 物块、陷阱、建筑 等）一律从 other 字典中查找。

子类后缀：类别支持 类别/子类 格式，如 地层/链接、物品/图标、物块/文本、物块/图标文本 等。工具会取 / 前的基础类别判断字典，查找逻辑与不带后缀时完全一致，输出时保留原始类别。

额外参数：片段可带后续参数，如 {{地层/图标文本|干涸沙漠|图标大小=28px}}。工具只替换第一个 | 后的中文名，后续参数会原样保留。

查找方式：在对应字典中，找到 值 等于「中文名」的条目，取其 键 作为 id，替换为 {{类别|id=键}}。

示例：

  • 若 other 中有 "geyser": "间歇泉"，则 {{陷阱|间歇泉}} → {{陷阱|id=geyser}}
  • 若 other 中有 "concretetile": "混凝土块"，则 {{物块|混凝土块}} → {{物块|id=concretetile}}
  • 若 main 中有 "bandage": "绷带"，则 {{物品|绷带}} → {{物品|id=bandage}}
  • 若 layer 中有 "Gravel_Lands": "砾石荒原"，则 {{地层|砾石荒原}} → {{地层|id=Gravel_Lands}}
  • 带子类后缀：{{地层/链接|干涸沙漠}} → {{地层/链接|id=Dried_Desert}}（按 地层 查 layer）
  • 带子类后缀：{{物块/图标|混凝土块}} → {{物块/图标|id=concretetile}}（按 物块 查 other）
  • 带额外参数：{{地层/图标文本|干涸沙漠|图标大小=28px}} → {{地层/图标文本|id=Dried_Desert|图标大小=28px}}

注意：已经转换过的 {{类别|id=xxx}} 不会被重复处理；未找到对应中文名的片段将保持原样并在下方列出。
